📦 PROJECT SUMMARY / RESUMEN DEL PROYECTO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Utils is a lightweight, reusable Python module with 17 functions for common
automation tasks. It includes keyboard control, file management, window
management, and utility functions - all well-documented and ready to use.

Utils es un módulo Python ligero y reutilizable con 17 funciones para tareas
comunes de automatización. Incluye control de teclado, gestión de archivos,
gestión de ventanas y funciones de utilidad - todo bien documentado y listo
para usar.
