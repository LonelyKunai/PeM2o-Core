COMMON PATTERNS / PATRONES COMUNES
═══════════════════════════════════════════════════════════════════════════════

Retry Pattern / Patrón de Reintentos:
─────────────────────────────────────
for attempt in range(1, max_attempts + 1):
    press_key(key, 0.3)
    if attempt < max_attempts:
        wait_random(0.5, 1.5)

Timed Loop / Bucle por Tiempo:
──────────────────────────────
import time
start = time.time()
while time.time() - start < 60:
    press_key('z', 0.3)
    wait_random(1, 2)

Configuration Loading / Carga de Configuración:
───────────────────────────────────────────────
if file_exists('config.txt'):
    config = load_config_file('config.txt')
    for line in config:
        process_line(line)

Window Management / Gestión de Ventanas:
─────────────────────────────────────────
hwnd, title = find_window_by_title("PokeMMO")
